# le goat

Two static versions of the same piece, in one site.

- [Interactive site](index.html) is the scroll prototype
- [Article](article/index.html) is the reading version
- [Sankey play](sankey-play.html) and [reply play](reply-play.html) are the motion studies

From this folder:

```
python3 -m http.server 8765
```

Published with Netlify. There is no build step. The site is `/` and the article is `/article/`.
